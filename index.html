Como funciona a administração

Separação de dados preservada.
O administrador consulta os estados individuais no Supabase sem trocar de login e sem substituir o próprio banco local. Pode visualizar a operação, promover/rebaixar outras contas, bloquear/desbloquear, resetar ou excluir contas e definir uma nova senha para outro usuário. A senha atual nunca é exibida, e as vendas de outra pessoa permanecem somente para leitura.
